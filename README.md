# 《半畝方糖》期中專題專案說明文件

## 1. 專案主題與核心理念
本專題以「城市中的慢活微旅行」為核心，聚焦於**帝國製糖廠臺中營業所**（星泉湖畔）。針對現代青年長期承受 3C 數位疲勞與生活焦慮的痛點，倡導利用零碎時間進行低成本的心靈重開機與城市輕旅行。

## 2. 網站架構與技術規格
本網站嚴格遵循響應式網頁設計（RWD）與模組化架構開發，包含以下 5 個獨立分頁：
* **首頁 (`index.html`)**：專題痛點觀察與解方提案總覽。
* **糖廠故事 (`story.html`)**：帝國製糖廠歷史背景與星泉湖生態介紹。
* **影展短片 (`film.html`)**：微電影故事大綱、短片播放及行銷企劃摘要。
* **走讀地圖 (`visit.html`)**：交通引導資訊與 Google Maps 嵌入地圖。
* **製作團隊 (`team.html`)**：8位組員的詳細分工表與職責說明。

## 3. CSS 樣式架構
為符合模組化與維護性需求，樣式表獨立拆分為以下 4 個檔案並存放於 `css/` 目錄中：
* `base.css`：重置與全站基礎字體排版設定。
* `layout.css`：網格系統（CSS Grid）與主要排版區塊（Header, Footer, 雙欄佈局）。
* `components.css`：卡片元件、響應式表格、影音嵌入框及邊欄 Widget。
* `responsive.css`：定義 900px 與 600px 斷點的 RWD 響應式媒體查詢。
